## 4.1 补记：用户实测发现的白屏崩溃（已修复）

用户点击赋值节点立刻白屏。根因：Inspector 草稿用 useEffect 在渲染**之后**按节点 id 重置——切节点后的**首渲染帧**拿的是上一个节点的草稿（call 节点无 value 字段），assign 分支的  读到 undefined 抛 TypeError。根治：草稿改为「node + 未提交覆盖层」渲染期派生（无首帧错位）；提交过的覆盖键随手清除，避免陈旧覆盖压过外部变更。补崩溃回归测试（call→assign 切换路径），223/223 通过。
