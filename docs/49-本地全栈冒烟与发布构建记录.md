主要 chunk（gzip）：`vexflow` 671.1KB（懒加载，编辑器五线谱/游玩谱面按需）、`GraphEditor` 93.2KB、`AiPanel` 72.4KB、`react-vendor` 65.8KB、`index` 50.6KB、`index.css` 19.4KB。

结论：首屏 gzip 约 203.5KB，不构成发布阻断；vexflow 仍是最大懒加载块。EXT-5 口径为**记录优先、超阈值再立项**，本处以记录闭环，不设硬阈值。

## 4. 限制与不宣称项

1. **本地 wrangler ≠ 生产 Cloudflare**：本地无边缘 CDN/缓存/实际域名，`_headers` 静态头与 worker 行为在本地接近但仍需生产部署冒烟（EXT-4 仍待环境）。
2. 本地 D1 数据非生产数据；admin/云盘/关卡库的**操作**（上传/发布/审核/删除）未逐项执行，仅验证登录态渲染与页面无错误。
3. 矩阵仍为 headless；真实用户拖拽/音频/触屏交互不在覆盖范围。
4. 本地 admin 密码只用于冒烟，seed SQL 已删除，未写入仓库/文档。
