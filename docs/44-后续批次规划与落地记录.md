### 1.2 实现

|---|---|

### 1.3 验证

- 定向：2 files / 14 tests 全绿；全量：**102 files / 929 tests 全绿**（39.71s）；`tsc` 0 错；`build` exit 0。

### 5.2 实现与安全

- 热路径改为**结构共享**：只复制 doc → content → 变更分支（table/rows、components、meta、logic.variables、views），未变更分支保持引用；
- 覆盖：`updateTableCell`、`updateComponent`、`updateTableColumnLabel`、`setTableColumnType`、`updateView`、`setFlow`、`setMeta`、`setVariable`、`renameVariable`、`removeVariable`；
- 历史栈安全前提：全仓禁原地 mutation——变换从不改写入参已共享对象，旧 doc 树不可变；未命中目标保持「返回新 doc 引用」语义；
- 新增 docState 结构共享回归 2 例（分支引用关系/入参不变/未命中语义）。
- **残余**：结构性增删（add/removeComponent/View/Column/Row）与整表替换（setTable）仍整体 `structuredClone`——非逐键热路径，保持简单可靠；后续如需再降，可按同一模式迁移但需逐项验证级联。

### 5.3 Bundle 评估（VexFlow，结论：暂不改造）

- 现状：`vexflow` 1,119.57kB / gzip 688.43kB 是构建 >500kB 告警来源；`StaffEditor.tsx`/`staffViews.tsx` 静态 `import 'vexflow'`；
- 但 `App.tsx` 对编辑器整体 lazy（`EditorPage` 懒加载），VexFlow 只在**打开编辑器时**进入，不在首屏；
- 进一步按需（TableGrid 里 `StaffPreview` lazy）收益有限（编辑器内首次切数据表/notes 单元格即触发），代价是表格行内 Suspense 闪烁 + 既有同步渲染测试（`.tstaff-svg svg`）需改异步，改动面与回归风险大于收益；
- 结论：本轮**不做** StaffPreview 懒加载；保留为后续 bundle 专项候选（若未来首屏/资源预算硬约束或编辑器打开成本成为指标，再评估）。
