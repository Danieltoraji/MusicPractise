# 30 - 编辑器调试模式（断点/单步/变量观察/实时日志/手动触发）

> 状态：已落地（2026-10-03）。
> 关联：docs/12 §7（GraphEngine 执行器）、docs/22 §8（节点图工作台）、docs/29（面板化布局）

## 1. 需求与边界

为「调试 AI 生成的关卡 / 排查自己的逻辑」提供原生调试能力：

1. **断点调试**：节点粒度断点，命中即挂起；
2. **单步执行**：逐节点执行（跨处理器接力——处理器末尾单步会停在接力的下一个处理器首节点）；
3. **变量观察与实时赋值**：运行中实时显示 `engine.vars`，可直接强设（不触发逻辑——观察/强设工具）；
4. **实时运行日志**：`onLogicEvent` 推送式日志流（区别于试运行日志的「事后查看」）；
5. **手动触发事件**：事件下拉 + JSON 负载，走 `session.dispatch`（与 UI 点击完全同路径）。

**边界裁决：Debug 模式只能在编辑器工作台开启**（节点图 tab 的 🐞 调试面板）。调试会话是一个内嵌的可暂停 LevelSession（不渲染真实组件、不播放音频），游玩页（LevelPage）与发布产物完全不受影响。

## 2. 引擎层：调试门控钩子

`GraphHost` 增可选 `debug: { gate(nodeId, event): Promise<void> }`。`runHandler` 在**每个节点执行前**：

```ts
if (this.host.debug) {
  await this.host.debug.gate(node.id, event)
  if (this.generation !== gen) return  // stop 期间被挂起的执行在此作废
}
```

引擎本质串行（drain 循环逐事件逐处理器），**单门控即可挂起整个执行流**。实现方契约：关闭/停止时必须 resolve 所有挂起门（否则处理器永久泄漏）。`LevelSession` 的 `SessionHost` 同步透传 `debug` 与 `budgets`。

## 3. 编辑器层

### 3.1 debugRun 管理器（`src/editor/graph/debugRun.ts`）

模块级单例 + 可订阅快照（`DebugSnapshot`：mode idle/running/paused、pausedAt/pausedEvent、breakpoints、events（上限 100）、vars 实时值、view/row/total、finished、loadErrors）。API：`startDebugRun(doc)`（loadLevelDoc 预检 → 建会话 → start → 400ms 低频刷新变量快照）、`stopDebugRun`、`resumeDebug` / `stepDebug` / `pauseDebug`、`dispatchDebugEvent`、`setDebugVar`（`__` 系统变量拒绝）、`toggleDebugBreakpoint` / `clearDebugBreakpoints`。

关键实现事实：
- 门控控制器：`breakpoints`（跨会话保留）+ `pendingStep` / `pendingPause`；挂起时 `commit({mode:'paused', pausedAt, ...})`——**必须写快照**（初版只 notify 不 commit，面板永远看不到暂停）；
- 变量终态/实时值必须在 `dispose()` 前采集（`engine.reset` 复位变量）；
- 停止 = 禁用门控 → resolve 全部挂起门（引擎按 generation 作废）→ dispose。

### 3.2 工作台集成

- 面板系统注册第 6 个 dock 面板「🐞 调试」（默认收起、默认位于右B 列 AI 之上，可自由拖换——复用 docs/29 全套布局机制）；
- **断点印在节点卡左缘圆点**（空心=未设/实心红=已设，点击切换），暂停中的节点琥珀描边呼吸高亮 + 面板内可一键画布定位；
- 工具栏「🐞 调试」切换按钮；`GraphCardData` 增 `bp/paused/onToggleBp`（节点卡签名缓存相应扩展）；
- 断点按控制器保存在内存（编辑器挂载生命周期），跨调试会话保留。

### 3.3 已知限制

- 暂停发生在**节点边界**——已启动的 wait 定时器继续走（到点后其后续节点同样被门控拦下）；repeat timer 长时间暂停会积累队列事件，恢复后可能触发 maxEvents 预算（表现为一条预算错误日志，非崩溃）；
- 调试会话不渲染真实组件：`runEffects` 被丢弃（无音频/无视觉反馈），以变量、日志、视图/行轨迹为准；
- 变量赋值不触发逻辑（无响应式系统）——用于强设状态后继续跑。

## 4. 质量门禁

- 引擎门控单测 3 例（断点挂起+赋值窗口+继续、单步逐节点、无断点直通）；debugRun 集成 3 例（教程关全流程：断点命中/变量赋值/继续/命令日志/停止复位；单步跨处理器接力；断点跨会话保留）；全量 **473/473** 绿。

## 6. 批次9：调试可视化——可见游玩画面 + AI 试玩同屏（2026-10-04）

Debug 会话从「无头」改为**可见的游玩画面**：调试会话激活时节点图工作台整体切换为调试布局——
左侧 = 可交互游玩画面（默认主导宽度），右侧 = 窄列（调试控制 + AI 助手，分隔条可拖拽 280–560 持久化
`graph-dock-dbg-w`）；停止后自动恢复编辑布局。AI 与人共用同一会话单例——**AI 试玩全程可见**。

### 6.1 会话地基（9a）

- **渲染源暴露**：`DebugSnapshot` 增 `stage: { doc, store, emitFor, sessionNo } | null`（doc = loadLevelDoc 装载副本）
  与 `rowData`（题面）。运行中 commit 不替换 stage 引用——组件状态由 per-session store 自己的订阅驱动。
- **真实音频**：`src/runtime/audioHost.ts` 抽出 `runAudioEffects/nowSeconds`（LevelRunner 等价重构共用），
  debug 会话 runEffects 从「丢弃」改为真实播放——「正常的游玩画面」应有听感。
- **暂停冻结计时器**：LevelSession 增 `setTimersPaused(paused)`——timers 改存 `{handle, ms, repeat, startedAt}`，
  暂停 clear 并记录 remaining、恢复按剩余重挂。**原因：timer 的 `__tick` 直改组件状态绕过引擎门控**，
  不冻结会出现「画面已暂停但倒计时还在跳」。debugHost.gate 挂起/放行时联动调用。
- `restartDebug()`：restart 语义重开（变量/组件/行复位；断点与快照事件流保留）。

### 6.2 画面与布局（9b）

- **DebugStage**（`src/editor/graph/DebugStage.tsx`）：`stage.doc.components` 按当前视图过滤 →
  `ComponentView spec/store/emit`（与玩家页同构，**无 inert、真实 emit**——画面点击即 session.dispatch，
  与 debug_dispatch/AI 触发同路径）。顶条：标题/视图/第 x/y 题/题面/`⏸ 已暂停于 {node}` 徽标；
  画布：800×470 玩家页坐标系 + ResizeObserver fit-scale（transform scale，窄面板不滚条）；底条：结算 + 「↻ 重开」。
  画面视口保持玩家页浅色观感，外框/顶底条随 ge-dark 主题。
- **GraphEditor 调试布局**：`debugSnap.mode !== 'idle'` 时渲染 `gdb-layout` 替换编辑三列 dock。
  工具条 = `▶/⏸ 调试运行中（暂停于 x）` 徽标 + ⏹ 停止调试 + 画面/节点图二切；左区 `gdb-main`
  画面（默认）/`graphCanvasArea` 节点图共用（断点圆点与暂停高亮在调试中依然可用）；
  右列 = DockPanel(调试面板) + gsplit-h + AiPanel。新会话启动（人或 AI）自动切到画面窗格。

### 6.3 AI 侧（9c）

- `capture_screen` 增 `target=debug`（调试运行画面；无可见会话给 debug_control 启动指引）；
  `debug_screenshot` 改为**优先截调试画面、回落节点图**（双尝试）。
- prompts 调试守则改写：debug_control(start) 启动的是**可见调试会话**，创作者实时看到 AI 触发的每个事件与画面反应。

### 6.4 边界

- 调试画面挂在节点图工作台：其它 tab 的 AI 面板启动调试会话后，切到节点图 tab 即见画面。
- 会话仍跑装载副本：调试中继续编辑图不实时进会话，重启会话生效（既有语义）。
- 暂停期间画面点击的事件**入队不执行**（引擎 drain 挂起的既有语义），恢复后按序执行。
