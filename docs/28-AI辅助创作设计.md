## 1. v2 裁决：AI 功能是 Agent 的

用户要求（2026-10-02）：

1. AI 通过 **tool 自主读取和编辑**脚本与 JSON（编辑后编辑器自动刷新）；
2. **自动试运行关卡**、读取运行日志与报错；
3. 画布 / 节点图 / 脚本 / 数据表共用**同一段多轮对话**；
4. Copilot 式体验：**ask / plan / agent 三模式**，可选中画面元素 / 图节点 / 代码片段进行提问和编辑。

**裁决变更**：原「AI 只产草稿、用户显式应用」修订为——ask/plan 保留草稿精神（只读/出计划），**agent 模式直接应用编辑 + 会话检查点一键回滚**（所有写入仍必须经 parseScript / lint / loadLevelDoc 校验）。批次的「一次性生成面板」方案全部被 Agent 工具化方案取代。

## 2. 可行性研究结论（2026-10-02）

- **无头试运行零改动可行**：`LevelSession`（src/runtime/levelSession.ts）完全不依赖 DOM/React。`levelSession.test.ts`、`tutorial.test.ts` 即无头驱动范本：`loadLevelDoc(doc)` → `new LevelSession(doc, recordingHost)` → `start()` → `session.dispatch('keys1.keyClicked', {midi:60})`（与 UI 点击同路径）→ 读 `engine.vars` 终态。日志经 `SessionHost.onLogicEvent` 直收（command/error 带 nodeId），无需绕道 sessionStorage。死循环由 GraphBudgets 拦截（maxNodes 512/处理器、maxEvents 64、exprSteps 1000）。唯一建议改动：`SessionHost` 增加可选 `budgets` 透传（~5 行）+ 驱动侧外层超时。
- **统一面板挂载**：EditorPage 五视图为条件子组件，`.editor-tabs` 后包 `.editor-body{display:flex;flex:1;min-height:0}`，AI 右栏与视图并列即可全 tab 常驻；子项必须 `min-width/min-height:0`（历史包裹层教训）。
- **选中上下文通道**：画布 `selected` 已在 EditorPage；节点图加 `onSelectedChange` 可选 prop；脚本页 textarea 加 `onSelectionReport`（行号+文本）；数据表暂用 tab 粒度。
- **检查点回滚**：模块级 `Map<doc.id, structuredClone(doc)>`（drafts 先例），回滚 = `update(snapshot)`。项目无撤销栈，此为 agent 模式安全网。
- **function calling**：全部预设供应商支持 OpenAI 兼容 tools 协议；`client.ts` 已扩展 tools 参数与 tool_calls 解析。

## 3. 架构

```
EditorPage（持 doc + update + aiSelection + docRef + aiOpen）
 └─ .editor-body（flex 行）
     ├─ 五视图（+ 可选选中上报 prop：GraphEditor.onSelectedChange / ScriptTab.onSelectionReport）
     └─ AiPanel（src/editor/ai/AiPanel.tsx，lazy，~360px 右栏，全 tab 共享）
          └─ 会话 store（src/ai/session.ts，模块级 Map<doc.id,{messages,busy,error}> + 订阅）
               └─ agent 循环（src/ai/agent.ts：chat→tool_calls→执行→回填→…→文本终止，maxTurns/停止）
                    ├─ client.ts（chatCompleteRaw + tools 参数）
                    ├─ 工具注册表（src/ai/tools.ts，exec(args, ctx)；ctx.getDoc 走 docRef→永远最新 doc）
                    └─ 上下文组装（src/ai/prompts.ts：system prompt 关卡清单 + 选中上下文前缀）
```

三模式语义：

| 模式 | 工具 | 行为 |
| --- | --- | --- |
| ask | 只读五件套 | 读取与诊断，不修改关卡（批次1） |
| plan | 只读五件套 | 调研后产出执行计划清单，用户确认后转 agent 执行（批次2） |
| agent | 只读 + 写入 | 自主编辑（直接应用自动刷新），会话开始自动存检查点、可一键回滚（批次2） |

## 6. 批次 2a 落地事实（写入工具 + agent，2026-10-03）

- **写入工具七件套**（`src/ai/tools-write.ts`，`WRITE_TOOLS` 导出）：`write_script`（parseScript 全文替换 logic，ScriptError 行列号回喂）/ `edit_table`（add_rows/update_cell/add_column/set_column_type/set_column_label/remove_row/remove_column——行 key ⊆ 现有列校验、类型枚举校验）/ `edit_components`（add 自动命名并回传新 id、type ∈ 契约注册表校验 /update/remove）/ `edit_meta`（difficulty 钳制 1–5）/ `edit_views`（add/rename/remove，末视图守卫）/ `edit_flow`（order/count/pass.expr）/ `set_variable`（set 接受任意 Json；`__` 系统变量拒绝）。docState 补 `setFlow` helper。
- **applyAndCheck 管线**：mutate → `loadLevelDoc(structuredClone(next))` 预检 → **通过才 `ctx.applyDoc(check.doc)`**（应用校验+规范化产物，走编辑器唯一写路径 update → 全视图自动刷新+标脏）；拒绝/抛错不应用，错误文本回喂模型自纠。`ToolContext` 增 `applyDoc`；AiPanel 新增必填 `onApplyDoc` prop（EditorPage 传 update、GraphEditor 传 onChange）。
- **agent 模式**：会话 store 增 `mode`（'ask'|'agent'，按 doc.id 记忆）；面板标题区 ask/agent 分段切换（plan 不出半成品按钮）；按模式选工具/prompt/maxTurns（ask 6 / agent 8）；agent 的 system prompt 注入修改守则（最小修改、先读后写、行 key 匹配、逻辑全文交付、以写入返回的校验结果为准）。
- **检查点回滚**（`src/ai/checkpoint.ts`）：agent 发送即存 structuredClone 快照（会话记 `checkpointAt`）；面板「↩ 回滚」= applyDoc(快照) + 会话追加回滚说明 + 清除检查点（单级撤销）。
- 门禁：新增 15 测试（toolsWrite 12 / checkpoint 3 / aiPanel agent 模式 3），全量 **458/458** 绿。

## 5. 关键实现说明（批次 0-1 落地事实）

- **供应商注册表**（src/ai/providers.ts）：DeepSeek / 智谱 GLM / OpenAI / Moonshot Kimi / 通义千问 / OpenRouter 均为 OpenAI 兼容单协议；自定义档案 id 前缀 `custom-`，程序化生成。
- **设置持久化**（src/ai/settings.ts）：localStorage 键 `ai-settings`（惯例同 graph-theme），缺失预设自动补齐、毒数据回落默认；Key 明文本机（静态站无后端），UI 注明不上传。
- **客户端**（src/ai/client.ts）：`chatCompleteRaw`（tool_calls 解析）+ `chatComplete`（纯文本便捷层）+ `testConnection`；错误分类 `bad-config / network / auth / rate-limit / server / bad-request / response` 全部可读中文，网络失败附 CORS 绕行建议。
- **会话 store**（src/ai/session.ts）：模块级 Map 按 doc.id 键，消息即 client 的 ChatMessage（含 tool 角色）；`subscribeAiSession` + `useSyncExternalStore` 驱动面板渲染；更新以新对象替换（快照稳定）。
- **agent 循环**（src/ai/agent.ts）：每关一个 AbortController（`stopAgent` 停止）；工具执行错误转文本回喂模型自纠；maxTurns（默认 6）防失控；system 消息每轮现组装不进会话历史。
- **只读工具**（src/ai/tools.ts）：read_script（generateScript，非结构化图降级节点清单）/ read_doc（分节摘要，rows 截 10 行）/ read_json（16k 字符上限）/ lint（loadLevelDoc + lintGraphProgramDetailed）/ read_run_log（读试运行 sessionStorage 日志）。
- **上下文**（src/ai/prompts.ts）：system prompt = 角色与边界 + LevelDoc v3 结构说明 + 当前关卡组件契约清单（id/type/事件/命令，来自 runtime/store 契约注册表）/ 变量 / 表列 / 视图 / flow；用户消息前缀 = `[上下文] 当前页面…；选中组件/节点（单行摘要）/脚本选区（行号+文本截 600）`。
- **面板**（src/editor/ai/AiPanel.tsx）：消息流（user 气泡 / assistant 文本 + 工具调用行 / tool 结果折叠卡）、Enter 发送、停止、清空、错误条、无 Key 去设置引导；编辑器 tabs 行尾「🤖 AI」开关。
