## 1. 设计定位：应用内的「深色逻辑工作台」

千星奇域的逻辑编辑器是游戏内一块**独立深色工作台**：深海蓝底、发光的类别色、克制的青色选中辉光、金色用于强调。本批把这一语言移植过来，并刻意保持**作用域隔离**——`.graph-editor` 子树整体换深色，应用其余页面维持浅色。节点图是编辑器中操作密度最高的视图，深色工作台让画布成为视觉主角，也让后续的连线/端口/状态色有更大的表达空间。

## 2. 交付物

| 项 | 内容 |
| --- | --- |
| 画布扩容 | 工作台高度 `calc(100vh - 158px)`（min 620px 兜底），画布随行自适应拉伸（原固定 720px）；节点卡放大 244×84（原 220×64），dagre 间距加宽（nodesep 44 / ranksep 112） |
| 深色主题 | 深海蓝玻璃面板（工具条/节点库/Inspector/变量/日志/右键菜单/对照图全套）；画布深空渐变 + 点阵网格（RF `colorMode="dark"` + `Background dots`）；节点卡深空渐变体 + 分类色带提亮（紫/蓝/绿/金/橙）+ 选中青色辉光、错误红辉光、相关虚线青框 |
| 端口与边 | 圆形彩色触点（真=绿/假=红/普通=石板蓝，hover 放大辉光）；执行边加粗描线，真/假红绿、普通石板蓝，选中青色辉光，箭头按端口配色（修复既有箭头无色问题） |
| 强调语言 | 青色 = 交互/选中；金色 = 模板/告警（模板项、「⚠ N 个问题」计数）；红 = 危险/错误 |

## 3. 评审结论（subagent 独立评审）

**结论：需修复后合并 → 已修复**（P0×1、P1×5、P2×6 全部处置；修复提交 acb72d2）。评审交叉核对了 RF v12.11.6 的 style.css 默认值与 marker 源码，确认 TSX 改动（colorMode/Background/layout/KIND_META）干净、作用域无外泄（57 条新规则全部带 `.graph-editor`/`.graph-canvas` 前缀；`.script-view`/`.ginsp-argdel` 等跨页类复用未受波及）、节点卡几何与布局兜底成立。

**P0（已修）**：工作台根未落深色底——问题列表的半透明金底透出 body 浅色，叠加新主题浅字 ≈1.16:1 不可见。修复：`.graph-editor` 根落深空渐变底 + 圆角（工作台意图的正确落点）。

**P1（已修，均为特异性/覆盖缺口）**：
- Inspector 模式切换 active 态被 `:not(x):not(y)` 通用规则的 (0,4,1) 特异性击穿 → 同级特异性后写夺回
- `ginsp-argdel` 排除项漏补深色样式（白底浅字 ≈1.27:1）→ 深色化 + danger 红回归
- 「⚠ N 个问题」金色被工具条按钮规则压过 → 专用 (0,3,1) 规则夺回金色 + 金边底
- MiniMap 节点用 RF dark 默认 #2b2b2b，深底 ≈1.2:1 → `nodeColor #41598c`
- 伪代码浮层唯一关闭钮白底浅字（既有缺陷，一并收口）

**P2（全部处置）**：操作未生效错误条深色化；日志旧 accent 色/低对比小字提亮；placeholder 提亮至 ≈4.5:1；「事件」紫提亮一档；边箭头按端口配色；Controls 融入深蓝。
