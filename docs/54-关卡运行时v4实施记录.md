## Round 5 · W2 第一批：通用解释器 + Flow main 执行器（2026-10-27）

**产出**
- `src/engine/v4/interpreter.ts`：v4 通用图执行器——
  - `CancelToken`（可注册取消回调）、`StepBudget`（步数预算）、`sleepWithCancel`（可取消休眠、钳制 0–600000ms）；
  - `GraphIndex`（节点/出边索引，按端口取唯一后继）、`runChain`（线性走链，无递归）；

  - `FlowHost`（ask/waitShell/setView/finish + SharedEnv + 调试 gate + 日志）；

  - finish 幂等（重复 warning 忽略）、finish 后白名单（含 finish 自身）、ask 后写 `local.<resultVar>`、restart 抛 `RestartRequested`。
- 测试：`interpreter.test.ts`（10 项）+ `flow.test.ts`（11 项）。

- `runChain` 只负责走链；每节点的 debug gate/预算/取消由 flow/session 组合（behavior 复用同一走链）。

## Round 6 · W2 完成：Behavior / V4Session / 无头 harness（2026-10-27）

**产出**
- `src/engine/v4/behavior.ts`：`BehaviorRunner`——
  - `run()` 派发 start；事件泵（queueMicrotask/FIFO）为每个匹配 `on` 创建独立异步任务（复用 `runChain`），任务间仅在 await 点交错，wait 不阻塞其它事件；
  - `emit` 入队后当前链继续、`return` 首个生效（归一化 QuestionResult 后立即结束，取消内部令牌/清队列，迟到任务静默退出）；
  - 错误归一（节点错误/预算 → error 结果、外部取消 → aborted、缺 on start → error）；预算：节点 2000/任务 64/事件 256。
- `src/runtime/v4/session.ts`：`V4Session` 会话内核——
  - 启动/重开/销毁生命周期（flow loop、restart 运行中取消重置 / 已结束直接重跑、dispose 中止）；
  - 四层作用域初始化（v/t/q.state 全表）、flow/behavior 双宿主实现、`stateOf/contentOf` 查询、命令/查询日志化失败；
  - ask 帧：槽位解析 + args 合并/类型校验 → surface store 挂载（绑定初值）→ BehaviorRunner + watchdog 竞速 → 结果映射/清理/`questionResults` 记录；
  - 绑定投影（初值合入 props + 变化检测按 `DATA_APPLY_COMMANDS` 下发命令）、shell/surface 事件路由、waitShell、视图切换、计时器（owner 分 shell/surface，可暂停）、运行日志与 `getDebugState`；
  - 只读观察：`questionResults`/`waitingShellEvents`/`isRunning`/`deck`/`seed`。
- `src/runtime/v4/harness.ts`：`runLevelHeadless(doc, {seed, script, timeoutMs})`——剧本化注入 shell/surface 事件、等待 surface/shellWait/result/finished、收集每题结果/结算/牌堆/日志；失败不抛异常，写 report.error。
- 测试：`behavior.test.ts` 10 项、`session.test.ts` 9 项、`harness.test.ts` 5 项。

**验证证据**
- `npx vitest run src/engine/v4 src/runtime/v4` = **12 文件 / 127 测试全绿**；`npx tsc --noEmit` exit 0。
- 全量回归 `npm test` = **125 文件 / 1155 测试全绿（41.20s）**（Round 5 后 1131 + 新增 24；schema 双校验 9 项在 `src/test/v4` 另计）。

**偏差与决策**
- V4Session 落在 `src/runtime/v4/session.ts`（依赖 ComponentStore/Effect，保持 engine 不反向依赖 runtime）；docs/52 文件地图与 docs/53 §10 已回填。
- 行为任务入口 = `on` 节点的出边后继（空 handler 不执行）；`return` 的非法形状经 `normalizeQuestionResult` 归一为 `status:'error'` 的 return 结果（session 原样交回 flow）。
- 绑定初始值直接合入 props 后 `store.init`（避免挂载后又下发同一命令）；运行期只对变化值下发命令。
- restart 语义补强：流程已结束时 `restart()` 直接重置并重跑（否则 pendingRestart 无 loop 消费）。

**W2 验收结论**：task-2 全部工作项（W2.1–W2.5）完成；最小 v4 关（自动牌堆 2 行、立即返回题型）无头跑通，score/passed/questions/deck/seed 齐全，watchdog 超时与 dispose 中止均有覆盖。关闭 task-2。
