# 29 - 节点图工作台面板化：AI 入坞 + 事件管理器 + 可拖拽布局

> 状态：已落地（2026-10-03）。
> 关联：docs/22（节点图美术升级）、docs/28（AI 辅助创作 v2·批次1 的统一对话面板）

## 1. 需求与裁决

1. **AI 助手入坞**：graph tab 内与「属性」面板平级、挂其右侧（画布 | 属性 | AI 三列），并**随节点图深浅主题换肤**（`.ge-dark` 作用域内）。其它 tab（画布/脚本/数据表/JSON）保留批次1 的编辑器右栏形态；两处不并存（graph tab 时 EditorPage 侧不渲染），同一 doc.id 的会话 store 保证切 tab 对话连续。**AI 开关收敛为单一总开关**（EditorPage `aiOpen` 下传，工具栏「🤖 AI」与各 tab 面板行为一致）。
2. **事件管理器（派生式注册表）**：不新增 schema 字段——事件清单实时派生：系统事件（关卡/题目/视图）+ 组件事件（各实例契约，外部来源）+ 内部事件（图中 on/emit 出现过的 `名:名`）。事件「存在」= 图中有节点引用；「新增内部事件」输入合法名（`^[A-Za-z_]\w*:[A-Za-z_]\w*$`）直接落 on 节点即注册。行内动作：**+ 处理器**（所有事件）；内部事件另有 **emit**（落 emit 节点）与 **定位**（focusNode 到首个处理器，仅 on 引用时可用）。带搜索。取代旧简版 EventsPanel。
3. **五面板平级可调（VS Code 式）**：组件库 / 事件管理 / 变量 / 属性 / AI 全部独立 dock 面板——各有标题栏 + ✕ 关闭；工具栏头部五个显隐切换按钮；**左栏与属性列、AI 列宽度可拖拽**（`.gsplit` 分隔条 + pointer capture，钳制 左150–360 / 属性240–460 / AI280–520）；**布局跨会话持久化**（localStorage）。

裁决边界：跨区拖动面板（如把属性拖去左栏）与面板折叠不在本批范围，留作后续候选。

## 2. 结构与持久化

```
.graph-editor.ge-{theme}
 ├─ .graph-toolbar  [🧩组件库|⚡事件|🧮变量|⚙属性|🤖AI 切换组] │ 既有按钮（整理布局/查看脚本/…）
 └─ .graph-layout（flex 行）
     ├─ .graph-left(width=leftW) → gdock ×3（组件库 flex:1、事件/变量 max-height 46%）
     ├─ .gsplit → .graph-canvas → .gsplit → .graph-right-col(width=inspW, 属性)
     │                                          └─ .gsplit → .graph-ai-col(width=aiW, AiPanel lazy)
```

- localStorage keys：`graph-panels`（显隐 JSON）、`graph-panel-w-left / -insp / -ai`（列宽，读时钳制防坏数据）。
- 新文件：`DockPanel.tsx`（面板外壳：标题栏+✕+内容区）、`EventManagerPanel.tsx`。
- Props 变更：`GraphEditor` 移除批次1 的 `onSelectedChange`（AI 入坞后 graph 选中直接内传，死路径清理），新增 `aiOpen` / `onToggleAi`。
- CSS：`.gdock-body > .glib/.gem/.gvars/.ginsp` 中和内部卡片样式（外壳统一供卡）；`.ge-dark` 补 AI 面板/gdock/gsplit/gem 深色全套；浅色补 `.graph-toolbar button.active` 反馈。
