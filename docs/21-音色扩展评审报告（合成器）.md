> 实现提交 9de8a84；评审修复提交见 §3。

## 1. 设计：为什么不扩采样、而做振荡器合成器

- 现有 `sound` 组件 = smplr 采样钢琴：音色真实但**需异步加载采样库**、只有一种音色、体积大。
- 合成器走**纯 Web Audio 振荡器**：零加载、即点即响，用波形 + 包络 + FM 调制 + 低通四个维度组合出多种音色——UGC 作者用一个组件即可覆盖芯片音/电钢/钟琴/拨弦等风格，是「音色扩展」性价比最高的路径。
- 与 `sound` 互补而非替代：钢琴采样留给「真实乐器」场景，合成器留给「反馈音效/风格化配乐」场景。

## 2. 交付物

| 层 | 内容 |
| --- | --- |
| 音频引擎（audio.ts） | `playSynth(notes, params)`：六音色 `sine/triangle/square/sawtooth/fm/bell`；每音色缺省包络手感（`SYNTH_VOICE_DEFAULTS`：attack/release/增益系数/自然衰减/fmRatio/fmIndex）；包络 = attack→hold（bell/fm 指数衰减）→release；FM = 载波 + 调制器（调制指数随时间衰减，产生「叮」感）；可选低通 `cutoff`；chord（20ms 微琶音）/seq（时值网格）排程与 `playNotes` 同语义；`stopSynth()` 静停全部声部；声部注册表 + 过期修剪防泄漏 |
| 组件契约（componentDef.ts） | `Effect` 新增 `audio.synth` / `audio.synthStop`；`SYNTH_DEF`：`play { notes, wave?, tempo?, mode?, attack?, release?, gain?, cutoff? }`（未传 wave/gain 用组件当前状态——props 或 setWave 设置的值）、`setWave { wave }`、`stop`；参数钳制 tempo 20-300 / attack 0-2 / release 0-2.5 / gain 0-1 / cutoff 0-12000，非法音色回退不损坏状态；`propsFields`：音色/音量（Inspector 表单可配） |
| 运行时接线 | store 注册 `synth`；LevelRunner 宿主处理 `audio.synth → playSynth`、`audio.synthStop → stopSynth`（效果通道与其余组件同一条链路） |
| 视图 | `SynthView`：深色面板 + 音色中文名（正弦·柔和/三角·木琴/方波·芯片/锯齿·明亮/FM·电钢/钟琴·空灵）+ 五道电平条动画（`playSeq` 驱动 900ms 脉冲）+ 音量/音符数元信息 |
| 编辑器 | 组件面板「音乐」组出现「+ 合成器」；节点库自动出现 `synth1 · play/setWave/stop` 动作；Inspector props 表单（音色/音量） |

## 3. 评审结论（subagent 独立评审）

**结论：无 P0；1 项 P1 已修复后合并**（修复提交 41f5d43，修复后 309/309 全绿）。评审以 mock AudioContext 探针实测包络事件时间线，确认排程/Web Audio 安全性（自动化事件单调、expRamp 前值非零、无节点泄漏竞态）与效果通道/编辑器集成面全部正确。

**P1（已修）**：非衰减音色（sine/triangle/square/sawtooth）的 sustain 平顶事件误落在 attack 尾（+1ms），指数释放从那时起插值——整个音符呈持续衰减、release 不构成独立段，seq 长音尾部近乎无声。修复：`setValueAtTime(peak, holdEnd)`（setValue 自带保持语义，平顶 sustain 成立），并沉淀 mock 包络回归测试锁定。

**P2 已修（择要）**：stopSynth 优先 `cancelAndHoldAtTime`（ramp 中途静停不再电平回跳）；play 参数 `Number.isFinite` 守卫（NaN 不再直达 AudioParam）；release 下限契约/引擎对齐 0.01；排程常数与 playNotes 对齐（25ms 琶音/+0.5s 尾/3.5s 上限）；`PropFieldDef.options` 通用扩展——合成器音色在 Inspector 渲染下拉（拼错值静默回退的口子关掉）；电平条动画 `key=playSeq` 重挂载重放（连续 play 动画不再停滞）；mode 非法告警与 sound 一致；mock 包络回归测试 4 例沉淀（评审探针转正）。

**P2 记录在案**：无（本批 P2 全部处置完毕）。

## 5. 使用示例（节点图）

```
on btn1.clicked → synth1.play { notes: [{midi:60},{midi:64},{midi:67}], wave: 'fm', mode: 'seq', tempo: 120 }
on level.finished → synth1.play { notes: [{midi:72,dur:'2n'}], wave: 'bell' }
synth1.setWave { wave: 'square' }   // 切音色（后续 play 沿用）
synth1.stop                          // 静停已排程音符
```
