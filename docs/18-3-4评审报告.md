## 1. 本批交付

- **画布真组件预览**：EditorCanvas 布局框内嵌 ComponentView 真渲染（专用 previewStore，组件初始态驱动，组件列表变化即重建）；预览层 `pointer-events: none` + `inert`（禁指针与键盘焦点），编辑交互全部由布局框接管；visible=false 组件以 is-ghost 幽灵框呈现；emit 为模块级 noop（不发声、不误发事件）
- **props 结构化表单**：ContractDoc 增 `propsFields?: PropFieldDef[]`（key/label/type/fallback），7 个组件契约补齐（label.text、button.text/enabled、staff.clickable、slider.min/max/step/initial、input.placeholder、fingering.lowMidi/highMidi、rhythm.countInBeats）——与 views/initialState 的运行时 fallback 逐一对照全部一致；Inspector 按 propsFields 渲染表单（boolean checkbox/number/string），props JSON 折叠为「高级」兜底
- **dirty-guard**：dirty state（update 标脏/save 清零）+ beforeunload 原生确认（含 Safari returnValue）+ hashchange **捕获阶段**确认（取消回滚 hash；回声抑制）+ 保存按钮「💾 保存 *」未保存标记 + 返回资源库链接确认
- 顺带：脚本页生成容错（非结构化图降级错误卡，见 3-3 补记）

## 2. 评审发现与修复（6e3371d）

| 级别 | 问题 | 修复 |
| --- | --- | --- |
| P0-1 | **dirty-guard 回滚必现二次确认，且二次「确定」会静默解除保护**：取消分支回滚 hash 触发第二次 hashchange，dirty 仍 true → 再 confirm；若第二次点「确定」，因 hash 已回滚完成，dirty 被清但用户留在编辑器——之后刷新/关闭全部不再拦截 | 回声抑制：handler 开头 `getLocationHash() === prevHashRef.current` 直接放行（回滚引发的事件天然命中）；「← 资源库」链接的 onClick confirm 删除（判定收敛到捕获 handler 一处，消除确定性双弹窗）；单测 4 例（干净放行/确认清脏/取消回滚+回声不重复确认/取消后再导航再确认） |
| P1-1 | Inspector 结构化表单与折叠的 props JSON 不同步：表单改完展开 JSON 显示旧值，再编辑即静默回退表单修改 | `<details onToggle>` 打开时同步 propsText = JSON.stringify(comp.props) |
| P1-2 | 本批三项交付 0 测试 | 补 VariablesPanel 4 例（未变更 no-op/JSON 解析/失败还原/重名后缀）、dirtyGuard 5 例、（propsFields 渲染经浏览器验收覆盖）|
| P2 已修 | 预览层只挡指针不挡键盘（Tab 聚焦可改预览滑块值）→ `inert`；emit 内联箭头 → 模块级 noopEmit 常量；beforeunload 补 `returnValue`（Safari） | 已落地 |
| P2 记录 | previewStore 每 keypress 全量重建（64 组件上限毫秒级，实测可接受；若将来预览注入 bindings 须改增量 sync）；staff 预览因 bindings 不注入为空框（降级语义待文档化/骨架）；孤儿告警链式刷屏（链头置顶待做）；props 混合类型显示（JSON 写 string 自愈）；props 交叉校验（lowMidi>highMidi） | 记录在案，按需后置 |

**专项确认**：previewStore 生命周期无竞态（useSyncExternalStore 重订阅安全、快照稳定引用、rhythm/tuner 无定时器泄漏/无 mount 自启麦克风）；propsFields 与运行时 fallback 7 组逐一对照一致；孤儿 lint 对迁移产物零误报。
