# docs/37 — 运行时 UI 改造

> 状态：**已全部落地**（2026-10-15，R1–R4 四批，722 测试全绿）
> 前置：docs/35（皮肤系统）、docs/36（UI 全量重设计）。docs/36 将「舞台内容层（comp-\*）」划为红线不动，本轮经用户裁决**解禁（只动 CSS）**；运行器框架层获批轻 DOM 重排。

## 1. 研究结论：运行时的真实形状

游玩运行时比传统音游「薄」得多——**没有暂停菜单/倍速/combo HUD/独立结算屏**。它是「数据即关卡」的组件化运行时：

```
LevelPage (.theater 剧场壳)                     ← docs/36 已剧场化
├─ .theater-top   返回 / 关卡标题 / 🧭逻辑图谱
├─ [lint 告警折叠]
├─ LevelRunner (.level-runner)                  ← 本轮重排主体
│  ├─ .level-head    题面 + 进度                ← 旧：标题重复显示 + 一行灰字
│  ├─ LevelStage     800×470 fit-scale 共享舞台 ← 契约：viewport/canvasClassName props
│  │   └─ 12 种 comp-* 内容组件（staff/label/button/choice/slider/input/
│  │      fingering/rhythm/tuner/synth/sound/timer(hidden)）
│  └─ .level-foot    重开 / 结算                ← 旧：结算后重开按钮消失
└─ [JSON 定义折叠]
```

- 舞台渲染 = DOM + SVG（VexFlow），非 canvas；fit-scale 等比缩放（`LevelStage.tsx`，与编辑器调试画面 DebugStage 单一真源共享）。
- 状态流：LevelSession（非 React 类）→ 4 个 useState 驱动渲染；组件状态真源在 ComponentStore。
- 结算只是一行 footer 文本；进度是纯文本「第 x / y 题」。

### 改造前问题清单（均已核实）

1. **体验缺陷**：关卡标题同屏显示两遍（theater-top + level-head）；题面（游玩第一焦点）是 head 里 13px 灰字；进度无进度条；**结算后「重开本关」按钮消失**（想再玩只能刷新）；结算无仪式感。
2. **全站旧账**：旧按钮基块（旧 index.css 634-661）写在 docs/36 组件层（304-356）之后，同特异性后者胜——全站按钮是「新层骨架+旧层外形」混合体。
3. **token bug**：`:root` 里 `--accent-soft/--accent-soft-strong/--warn-banner-bg/--warn-banner-ink` 是循环自引用（CSS 自定义属性循环 = 无效声明），真值只在皮肤块——被「默认 dream 常驻」掩盖；浅色岛漏钉 `--accent-soft` 全家 → 深色皮肤下琴键 hover 底色漂移进舞台。
4. **comp-\* 硬编码色散落**：comp-button `#f4f5fa`、comp-unknown `#fffbeb`、choice 判定底 `#f0fdf4/#fef2f2`、琴键四色、tap-pad 两个 rgba、synth/sound 全暗渐变。
5. **框架层旧 px 语言**：level-runner 区块 radius 14px/13px 字号；移动端 ≤720px 仅两条规则，theater-top/foot 无适配。
6. **异常态与图谱页旧语言**：loading 纯文本、未找到/校验失败用 breadcrumb+boundary-error 旧样式；GraphPage 整体旧样式。

### 测试边界（本轮全程遵守）

- **无钩子可重构**：`level-runner/theater/level-*/result-bar` 全套无任何测试引用。
- **必须保留**：`.stage-viewport/.stage-canvas/comp-*/.choice-item/is-correct/is-wrong/.key.white/.key.black/[data-midi]/[data-hitpad]/.tap-pad` + 文案（TAP/未开始/试音提示等）+ `gdb-stage-*`（DebugStage 经 props 复用 LevelStage 的契约）+ `.pass/.nopass` 类名（badge/gdb 复用）。

## 2. 设计裁决（用户确认）

| 裁决点 | 结论 |
|---|---|
| comp-\* 内容层红线 | **解禁，只动 CSS**（组件逻辑/类名/文案零改动） |
| 框架层 DOM 重排 | **允许**（不动 LevelSession/store/视图分发逻辑） |
| 全站旧按钮基块 | **纳入本轮清理** |
| 舞台浅色岛 | **保留**（乐谱可读性优先，深色皮肤下舞台仍纸面浅色） |
| 不做的 | 暂停/倍速/combo/血条等音游化功能（保持「数据即关卡」极简哲学）；编辑器内部工作区；生产端 |

## 3. 落地记录

### R1 全站按钮旧账清理（2bfc6d0）

- 删除旧按钮基块（旧 634-661：`button.primary`/裸 `button`/重复 `button.link`），docs/36 组件层成为唯一真源——全站按钮统一为 r-md 12px / fs-1 13.5px。
- 修复 `:root` 循环自引用 ×4：`--accent-soft: #eef1ff`、`--accent-soft-strong: #dfe3ff`、`--warn-banner-bg: #fdf6e3`、`--warn-banner-ink: #9a6700`（此前 dream/liuhua 下警告徽章实际渲染透明底+继承色）。

### R2 舞台内容层精修（5869a86，纯 CSS）

- **浅色岛钉值补全**（`.stage-canvas, .editor-canvas`）：新增 `--accent-soft(-strong)(-2)/--ok-soft(-strong)/--bad-soft(-strong)/--warn-soft(-strong)/--warn-ink(-2)/--shadow-rgb`，堵死皮肤漂移。
- **新增 `--st-*` 内容层子令牌**：琴键（`--st-key-white(-soft)(-hover)/--st-key-black(-line)(-hover)/--st-keybed`）+ 暗设备面板（`--st-device-synth-bg/ink/muted`、`--st-device-sound-*`）——synth/sound 的「暗设备」隐喻与钢琴键是内容原语，恒定不随皮肤。
- **硬编码色全部收编**：comp-button→`var(--soft)`、comp-unknown→`var(--warn-soft)`、choice 判定底→`var(--ok-soft)/var(--bad-soft)`、tap-pad 光晕→`color-mix(in srgb, var(--accent/ok) N%, transparent)`（顺带修了工具页 tap-pad 的皮肤漂移）。
- **视觉精修**（类名/文案零改动）：
  - choice 卡片化：hover 提边+投影、active 按压、判定态题号徽章（A/B/C/D 圆片变绿/红底白字）；
  - 琴键立体感：白键底边内阴影+按下沉降、黑键底边高光、correct/wrong 保持 `var(--ok)/var(--bad)`；
  - 节拍垫 live 态呼吸动画（`tap-breathe`，全局 prefers-reduced-motion 通杀块自动覆盖）、beat-dot 软底+active 光环；
  - comp-label tone 软底色带化；comp-staff/comp-tuner 圆角令牌化+纸面投影；comp-input focus ring（`var(--focus-ring)` 为派生 token——岛内 pin 了 accent 后**必须在岛作用域重算**，R22 已落地；原「自动用钉住 accent 计算」的表述被 docs/40 G4 证伪）。

### R3 运行器框架重排（bf62c14，轻 DOM）

- **LevelRunner**：head 去掉重复标题；题面升级 `.stage-prompt` 主视觉条（`第 n 题` accent 徽章 + fs-3 题面大字；空 prompt 不渲染整条）；进度条化 `.level-progress-track`（渐变 fill = (index+1)/total，`transition: width var(--tr)`）+ `x / y` 计数。foot 重构：未结算 = 「↻ 重开本关」；结算 = `.result-bar`（🎉通过 绿 / 💪未通过 琥珀 + 得分 + **「↻ 重玩」「← 回首页」常驻**——修复结算后无法重开）。
- **LevelPage**：theater-top 三钮化（`.theater-back`/`.theater-graph` 安静按钮 + 标题 display 字体居中）；lint/JSON 折叠降噪（fs-0 muted）；loading 态入 theater 壳（`.theater-empty` 防跳动）；未找到/校验失败 page-head 化。
- **GraphPage**：page-head 化（标题+副文+返回首页/试玩此关/编辑此关动作区）。
- **ErrorBoundary**：`.boundary-runtime` 修饰类保持居中（`.boundary-error` 本体改左对齐服务校验失败列表）。
- **移动端**：theater 收窄、theater-title 独占一行（`order:-1` + 换行）、题面条/结算条缩字号。
