# 36 · UI 全量重设计（基于内容需求的重新设计）

> 状态：落地中。承接 docs/35：皮肤系统、文档页、令牌化基建保留；本篇把**骨架与页面全部按内容重新设计**，不是在旧 UI 上改配色。红线不变：不改任何功能逻辑；编辑器内部工作区（ge-\* 体系）、关卡舞台内容层（comp-\*）为内容层不动；不动生产端。

## 1 · 调研：逐页显示内容需求与现有问题

### 1.1 全局外壳

**内容需求**：8 个顶层目的地（首页/资源库/文档/校音器/节奏/皮肤/设置/管理员），账户态显示，工坊页（编辑器/节点图）需要更宽工作面。
**现有问题**：P0 顶栏不固定，滚动后导航消失；P0 窄屏导航与品牌折行错乱（实测「音乐练 习」两行）；P1 960px 单列文档流让应用「像文档不像应用」，工坊页外全部浪费宽度；P1 导航无当前区的空间归属感（一排文字链接）；P2 无账户位（昵称藏在链接里）。

### 1.2 首页

**内容需求**：两类内容（专题系列=成套课程；独立关卡=散题）+ 两个技术 demo + 设置入口；每关有难度星/组件数/题数/通过徽章/最佳分；系列有专题数。
**现有问题**：P0 hero 是「README 段落」（讲 JSON/节点图实现细节，玩家不关心）；P1 四组内容平铺同权重，「风险验证 Demo」「设置」混在内容里；P1 卡片无视觉锚点（纯文字卡），系列卡与关卡卡难区分；P2 通过徽章挤在标题行。

### 1.3 资源库

**内容需求**：三类分组（教程与示例/系列树/未整理），树形（系列▸专题▸关卡），全文搜索，导入/AI 新建/返回，导入报告，逐行操作（试玩/编辑/导出/删除，触屏常显）。
**现有问题**：P0 操作按钮排最前且全是 primary 实心，视觉噪声大、主次不分；P1 树分隔符弱（一行小字），分组感差；P1 行内 id 一长串灰字抢占视觉；P2 搜索框与按钮混排无工具栏结构。

### 1.4 系列页

**内容需求**：系列头（标题/描述）+ 专题分节 + 关卡行（标题/星/题数/徽章）+ 缺件提示。
**现有问题**：P1 hero 与首页重复语言；P1 关卡行是纯 flex 行，进度徽章与题数排布松散；P2 缺少系列级进度汇总（显示需求：完成 X/Y——由已有 progress 数据可推导，属显示层）。

### 1.5 关卡游玩页

**内容需求**：面包屑/逻辑图谱入口、题面舞台 800×470（纸面）、lint 告警、JSON 折叠查看、结算。
**现有问题**：P0 「白面板+白纸面」文档感强，无舞台沉浸；P1 面包屑与 lint/JSON 折叠条散在页面上方；P2 结算与重开样式弱。

### 1.6 编辑器

**内容需求**：五视图切换、标题/撤销重做/保存/试运行、左侧五 dock 面板、画布、AI 助手、lint/保存反馈条。
**现有问题**：P1 头部工具条元素间距与分组随意（返回链接、标题输入、四个按钮一排平铺）；P1 Tab 条是普通按钮排；P2 chrome 与工作台主题两套语言并存。**内部工作区（dock/画布/节点图/数据表/五线谱）保持不动**。

### 1.7 设置 / 校音 / 节奏 / 管理 / 文档 / 皮肤中心

- 设置：P1 无分节结构（账户/云盘/AI/音频一滚到底）；P2 表单无栅格。→ 分节卡 + 页头锚点。
- 校音/节奏：P0 页面标题直接 h1+段落，无页头结构；工具面板语言与全站脱节。→ 统一 page-head + 工具卡。
- 管理：P0 无页头、四区块平铺；表格样式与全站脱节。→ CSS 层接入新语言（不动 DOM）。
- 文档/皮肤中心：docs/35 新建，结构已对齐目标；按新设计语言统一排版尺度与控件。

## 2 · 新设计语言「声窗 Soundframe」

一句话：**应用外壳 + 内容卡 + 剧场舞台**。桌面固定侧边栏 + 全宽主区（对齐需求参考的 DeepSeek 布局范式）；移动端品牌行 + 横向导航 chips。

### 2.1 设计令牌 v3（新增，旧名保留为内容层 API）

```
间距   --sp-1..8: 4/8/12/16/24/32/48/64
圆角   --r-sm 8 · --r-md 12 · --r-lg 16 · --r-xl 22 · --r-pill 999
字阶   --fs-0 12 · --fs-1 13.5 · --fs-2 15 · --fs-3 17 · --fs-4 20 · --fs-5 24 · --fs-6 30
       行高 1.65 正文 / 1.25 标题
阴影   --shadow-1 边缘浮起 · --shadow-2 卡片悬停 · --shadow-3 浮层
色彩   新角色：--shell-bg/--shell-ink 侧边栏 · --surface 面板(=--panel) · --focus-ring
       旧名映射不变：--bg/--panel/--panel-2/--soft/--line/--ink/--muted/--accent/...
动效   --tr 180ms ease · --tr-fast 100ms；悬停位移 ≤2px；respect prefers-reduced-motion
```

### 2.2 外壳

```
┌────────┬──────────────────────────────────┐
│ ♪ 品牌 │  主区（全宽，每页自建页头）        │
│        │                                  │
│ 首页   │   page-head: 标题+副文+动作区      │
│ 资源库 │   ────────────────────────────   │
│ 文档   │   页面内容                         │
│ 校音器 │                                  │
│ 节奏   │                                  │
│ …      │                                  │
│ 🎨皮肤 │                                  │
│ ⚙设置 │                                  │
│ 👤昵称 │                                  │
└────────┴──────────────────────────────────┘
```

- 侧边栏桌面 216px 固定 sticky 全高；工坊页（编辑器/节点图）自动收成 60px 图标栏（`:has` 驱动，无 JS）；导航项 = 图标+文字，当前项左侧 3px accent 指示条 + soft 底。
- 移动端 ≤720px：侧边栏变为顶部品牌行 + 横向滚动导航 chips；账户入设置页。
- 背景图/水印层保持全视口 fixed，位于内容之下（scope=home 仅首页显示）。

### 2.3 组件层

按钮四型（primary 实心 / default 面底描边 / ghost 无底 / danger 文红），统一 `--r-md`、`--tr-fast`；输入统一 `--panel-2` 底+focus accent 描边+外发光 ring；卡片 hover 升起（shadow-2+translateY(-2px)）；徽章 pill 化；页头 page-head 全站统一。

### 2.4 逐页方案

| 页面 | 重设计要点 |
| --- | --- |
| 首页 | ① 品牌横幅（渐变板+标题+一句话+两个快捷按钮：去资源库/新建关卡）②「系列」书架横卡（图标位+标题+专题数+描述）③「独立关卡」网格卡（顶行难度星+来源徽章，中标题+描述，底 meta+进度徽章右对齐）④ demo 与设置收进「工具」单行小区块 |
| 资源库 | page-head（标题+计数+搜索右置）+ 操作组（导入/AI 新建为 primary 组，返回为 ghost）+ 分组标题行强化（图标+计数）+ 树行：图标/标题/徽章左，id 弱化为 title 提示+操作右 |
| 系列页 | 系列头卡（大标题+描述+进度汇总 X/Y）+ 专题分节（节头图标+计数）+ 关卡行双列对齐（左标题+星，右徽章+题数） |
| 游玩页 | 剧场化：`.theater` 深幕容器（全宽）+ 顶部信息条（返回/标题/图谱）+ 舞台窗（纸面浅色岛居中）+ lint/JSON 折叠收进剧场底部工具行 |
| 设置 | page-head + 分节卡（账户/云盘/AI 供应商/音频/外观）节内表单栅格 |
| 编辑器 | chrome 重设计：头部=分组工具条（返回｜标题输入弹性｜撤销重做｜保存/试运行）+ Tab 条分段控件化 + AI 切换钮右置；内部工作区不动 |
| 管理 | CSS 接入：区块卡化、表格 th 底色、行悬停 |
| 校音/节奏 | page-head + 工具卡面板化 |
| 文档/皮肤中心 | 排版尺度对齐（--fs-*/--sp-*），控件统一四型按钮 |

### 2.5 皮肤按新 token 重调

dream=暖纸感浅色（shell 同底微深）；violet=白+紫，shell 白；liuhua=深蓝+冰蓝+金，shell 更深一档（--shell-bg 独立变量，比内容面板更深，拉开层次）。
